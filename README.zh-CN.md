# Pawse 🐾

**一只小猫，帮你办点事。**

Pawse 是一个计划通过语音交流、帮助用户处理线上任务的 AI 猫咪助手。项目名为 **Pawse**，其助手概念暂称 **CatAgent**。

[English](README.md) · [产品规格](docs/SPEC.md) · [活动说明](docs/HACKATHON.md)

## 为这次 Hackathon 而构建

本项目专门为 **Tech Europe AI Hackathon** 构建，该活动由 **Google DeepMind** 赞助。我们计划使用 Gemini API、Gemini Live API 和工具调用，做出一个能听懂任务、执行操作并用语音汇报结果的猫咪助手。

这是独立参赛项目；活动赞助不代表 Google 或 Google DeepMind 对本产品的背书。

## 想实现的体验

你说：“Pawse，帮我把这个网页整理成三个重点。”

猫咪调用应用提供的网页读取工具，整理结果，在界面显示摘要并用语音回复。

**以上是目标演示，并非已经实现的功能。** 当前仓库只有项目文档和基础配置，尚无可运行应用、在线演示或经过验证的 API 接入。

## 第一版范围

- 猫咪界面，以及待机、聆听、执行、说话状态。
- Gemini Live 实时语音对话。
- 一个真正能执行的线上任务工具。
- 对话转写、执行状态和结果展示。
- 麦克风权限、连接失败及任务失败的基本处理。

技术栈和第一个任务工具仍待确定。模型负责提出工具调用，实际操作必须由我们的代码执行，不能把模型回复当作执行成功的证明。

## API 接入计划

后端保存 `GEMINI_API_KEY`，前端通过后端签发的短期 token 连接 Gemini Live；工具调用交给应用后端执行，结果回传给模型生成语音回复。

开发者可先在 [AI Studio](https://aistudio.google.com/api-keys) 中登录主办方分配的临时账号、导入项目并创建 Key。`.env.example` 仅为后续实现提供配置参考，目前没有启动命令。

活动临时账号可能在比赛结束次日被删除。比赛结束前需保存代码和素材，后续改用自己的项目与凭据。请勿把真实 Key 提交到 GitHub 或放入浏览器代码。
